## Decision vocabulary and global rules

- `preserve`: carry forward a fork-only non-analytics behavior or an immutable published migration.
- `adapt`: port a fork-only non-analytics behavior selectively onto the upstream v0.12.4 contracts; never replace a mixed target file wholesale.
- `upstream-standard`: use the exact target blob or absence. All custom Prompt Insights, routing-analytics, custom TTFT/token-rate/error UI/API/test/translation deltas are **excluded**; retain the target upstream Analytics endpoints, UI, counters and translations.
- `provenance`: retain historical artifacts for reference only; never replay patch archives or restore old plans/specs as implementation.
- Published Prompt Insights migrations `f8a9b0c1d2e3` and `6c7d8e9f0a1b` are immutable and preserved with existing schema/data. No revision edits, drops, destructive cleanup, or data deletion. The separate fork merge revision is adapted only as needed for a non-destructive migration graph.
- Every non-analytics `preserve`/`adapt` path below has a later task owner and focused check. Checks are planned ownership gates; this Task 1 inventory did not run application tests.
